== Numeric Notes

You can use MIDI note numbers directly:

[source]
----
36 38 42 39   -- Same as: bd sn hh cp
60 62 64 65   -- C4 D4 E4 F4
----

Any integer 0-127 is valid.

== Sample Variants

Use `:n` to select variants:

[source]
----
bd:0    -- First variant (base note)
bd:1    -- Second variant (base note + 1)
bd:2    -- Third variant (base note + 2)
----

In the default mapping, `bd:1` maps to note 37 (rim shot).

== Custom Mappings

To create a custom drum map, edit `src/Tidal/MIDIScheduler.purs`:

[source,purescript]
----
-- 808-style kit
my808Map :: Map String Int
my808Map = Map.fromFoldable
  [ Tuple "bd" 36      -- 808 kick
  , Tuple "sd" 38      -- 808 snare
  , Tuple "lt" 41      -- 808 low tom
  , Tuple "mt" 45      -- 808 mid tom
  , Tuple "ht" 48      -- 808 high tom
  , Tuple "ch" 42      -- 808 closed hat
  , Tuple "oh" 46      -- 808 open hat
  , Tuple "cy" 49      -- 808 cymbal
  , Tuple "cb" 56      -- 808 cowbell
  , Tuple "ma" 70      -- 808 maracas
  , Tuple "cl" 75      -- 808 claves
  , Tuple "conga" 63   -- 808 conga
  ]
----

== Melodic Notes

For melodic patterns, use MIDI note numbers:

[source]
----
-- C major scale (C4 to C5)
60 62 64 65 67 69 71 72

-- Pentatonic scale
60 62 64 67 69

-- Chord (stacked)
[60, 64, 67]   -- C major triad
----

== Channel Configuration

Default channel is 10 (drums). To change:

[source,purescript]
----
midiConfig :: MIDIConfig
midiConfig =
  { device: "IAC Driver Tidal"
  , channel: 1    -- Change to channel 1 for melodic
  , velocity: 100
  }
----

== Velocity

Default velocity is 100. Pattern-based velocity control is planned for future versions.
